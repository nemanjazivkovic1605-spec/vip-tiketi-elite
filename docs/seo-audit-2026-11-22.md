# SEO provera i izmene, 22.11.2026.

## Pocetno produkcijsko stanje

- Pocetna: HTTP 200, oko 25 citljivih reci bez JavaScript-a.
- `/fudbal`: vec je imao serverski HTML sa rezultatima i ispravnim canonical-om.
- `/sitemap.xml`: HTTP 200/XML, 570 URL-ova, ogranicen izbor utakmica.
- Javni API je prijavio osam liga i 10.138 zavrsenih utakmica u dostupnom uzorku.
- Nepostojece adrese vracale su HTTP 200 i istu tanku pocetnu stranu.
- DNS Google verification zapis postoji. Vlasnicki Search Console nalog nije
  bio dostupan kroz browser alat; indeksiranje nije moguce zakljuciti samo iz
  javne `site:` pretrage ili DNS tokena.

## Uradjeno

- Prerender sedam postojecih javnih stranica iz istih komponenti, bez mreze ili
  pristupa bazi tokom build-a. Pocetna sadrzi oko 490 citljivih reci i vidljiv
  hero bez JS-a. Klijentska hidratacija nema prijavljene greske.
- Timovi, pojedinacni timski profili, H2H parovi i danasnji statisticki pregled
  koriste samo postojeci licencirani javni SQL snapshot.
- Zemlja je deo identiteta tima. Nepoznati timovi/parovi vracaju 404, a ne
  izmisljene podatke. Preokret se pripisuje timu koji ga je stvarno napravio.
- Postojeci canonical URL-ovi liga i utakmica su sacuvani; dodati su interni
  linkovi izmedju timova, liga, utakmica i H2H stranica.
- Jedinstveni naslovi, opisi, canonical/OG i strukturirani WebSite,
  Organization, SportsTeam, SportsEvent i BreadcrumbList podaci. Nema
  izmisljenih ocena, kvota ili garancija zarade u strukturiranim podacima.
- Sitemap index i segmenti do 1.000 URL-ova obuhvataju sav dostupan javni skup,
  ne samo poslednjih 600 utakmica. Filteri/pretraga ne stvaraju indeksabilne
  kombinacije URL-ova. Ne izmisljaju se datumi izmene.
- Poznate SPA rute su eksplicitne, a ostale adrese vracaju pravi 404.
  Privatne/auth stranice imaju noindex. API alias-i i cron URL-ovi su sacuvani.
- Kontakt forma koristi POST i u HTML-u, da bez JS-a ne salje licne podatke
  kroz query string. Postojeci submit handler i email logika nisu promenjeni.

## Provere

- `npm test`: 229 proslih, 0 neuspesnih testova.
- `npm run lint`, `npm run typecheck:api`, `npm run build`: prosli.
- Izolovani browser: 0 runtime/hydration gresaka, 0 Firestore write zahteva,
  0 admin bundle zahteva za gosta. Mock utakmice postojale su samo u lokalnom
  test procesu, nikad u produkcionoj bazi.
- Pregledi testirani na 1366, 1024, 900, 768 i 390 px bez horizontalnog scroll-a.
- Lokalni `vercel build` i `npm run vercel:functions:check` potvrduju devet
  stvarno zapakovanih funkcija, tri preostala Hobby mesta i najvecu funkciju
  ispod 9 MiB. Produkcijski deploy se dodatno proverava posle objave.

## Preostalo van tehnickog build-a

Vlasnik treba u Search Console-u da proveri Domain/URL-prefix property,
potvrdi sitemap `https://eliteviptips.com/sitemap.xml` i pregleda URL Inspection
za pocetnu, jednu ligu, tim i utakmicu. Ne koristi se Indexing API za sportske
stranice, ne menjaju se postojeci DNS verifikacioni zapisi i ne aktiviraju se
placeni SEO servisi.
